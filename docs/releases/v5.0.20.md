# Fame Codex v5.0.20

This release refreshes the launcher interface and reduces renderer work on lower-powered computers while preserving the existing setup and runtime behavior.

- Redesigns Connections setup as clearer, responsive step cards with simpler surfaces and navigation states.
- Removes decorative continuous motion and shortens panel transitions while respecting reduced-motion preferences.
- Reduces repeated browser-surface bounds IPC when geometry is unchanged.
- Updates the manual-turn countdown once per displayed second instead of four times per second.
- Preserves existing Activity rows as new records arrive and skips rendering offscreen rows where supported.
- Keeps ChatGPT sign-in, Codex setup, MCP credentials, tunnel configuration, and runtime control behavior unchanged.

Validation includes version synchronization, launcher TypeScript checking, renderer tests, production build verification, and responsive cockpit smoke coverage.
