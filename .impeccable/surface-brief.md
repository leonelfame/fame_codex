# Terminal desktop launcher

MODE: Operate
FORM: User-pinned Terminal/TUI replacement world. New-work seed ran; the explicit terminal brief overrides unrelated catalog forms. Code-led compact application, no image comp.
BUILD: Code-led desktop application; no approved image comp.

## Direction contract

- Near-black blue-tinted ground, pale blue foreground, thin square frames and installed monospace fonts. Blue replaces green per the user's latest explicit preference.
- Horizontal numbered text navigation, full-width framed work pane, profile/status/version footer. This replaces the left-sidebar composition.
- Real Alt+1 through Alt+6 navigation shortcuts; never intercept editing in inputs. Actual [x] and [ ] switches with semantic switch roles.
- 40px titlebar, 880x640 initial window and 640x520 minimum. Below 680px the menu becomes a toggleable tray; closed controls are inert.
- No decorative blur, page entrance animation, spring layout animation, GIFs, tutorial videos, or media player.
- Preserve every existing task, profile boundary, setting, localized message, and connector workflow.

## First viewport

Title and DEV marker at top; numbered navigation; a framed task pane; real status strip below. Settings uses aligned rows and text switches. MCP uses named steps and a pinned action footer. The embedded ChatGPT content remains a native browser surface.

## Signature interaction

Keyboard or mouse switches task surfaces immediately. Controls retain keyboard focus and visible selection. No fabricated telemetry, pretend commands, glow, texture, decorative effects, downloadable fonts or new UI libraries.

## Resource boundaries

No changes to active ChatGPT browser throttling or tunnel execution. Media and motion dependencies stay removed. Logs remain batched; Activity clocks run only during tasks and pause while hidden. Limits reads every10 seconds on the visible Limits page and every60 seconds elsewhere for cached status; hidden windows stop reads and manual mode does not continually poll. Bundle size is payload evidence, not an end-to-end RAM/CPU benchmark.
